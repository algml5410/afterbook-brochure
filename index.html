출처: AfterBook 자체 사용자 설문조사(2026년 10월 7~8일) · 총 응답자 28명 중 최근 3개월 내 예약 경험자 25명 분석. 56%와 40%는 불편 요소 선택(복수응답) 응답이에요.

설문에서 확인한 사실

  • 예약 경험자 대부분이 방문 전에 예약 정보를 다시 확인했어요(96%).
  • 일부 사용자는 필요한 예약 문자나 메시지를 다시 찾는 과정에서 불편함을 경험했어요.

다만 다시 확인하는 행동이 많다는 사실만으로 모든 사용자가 불편을 겪는다고 단정할 수는 없어, 실제로 탐색 부담을 줄이는지는 추가 검증이 필요해요.

핵심 인사이트

  • 예약 정보는 한 번 확인하고 끝나는 정보가 아니라, 필요할 때 다시 찾아보는 정보예요.
  • 그래서 새로운 예약을 만드는 기능보다, 이미 받은 예약 정보를 간편하게 등록하고 필요할 때 한곳에서 다시 확인하는 경험에 집중했어요.

05 — 제작 회고

만들며 배운 것

Keep

잘 된 점

설문으로 막연했던 정보 분산 문제를 '예약 이후 필요한 정보를 다시 찾는 불편'으로 구체화했어요. 추출·확인·수정, 일정별 조회를 구현하고, 카테고리 필터와 D-day 등 저장 이후의 사용 경험까지 개선했어요.

Problem

아쉬운 점

안내문마다 다른 형식과 한글 이미지 인식 오류로 정보 추출이 어려웠고, 수정할 부분이 많으면 오히려 입력 부담이 커질 수 있음을 알게 됐어요. 실제 사용자 검증이 부족했고, 브라우저별 저장이라 여러 기기에서 같은 예약을 볼 수 없는 한계도 있어요.

Try

다음에 시도할 점

다양한 예약 안내문으로 사용자 테스트를 진행해 추출 정확도·수정 빈도·등록 소요시간·완료율을 확인하고, 기존 메시지·앱 탐색과 비교해 실제로 탐색 부담이 줄어드는지 검증할 계획이에요. 그 결과로 입력 과정을 개선하고, 여러 기기에서 안전하게 확인할 수 있는 동기화 방식도 검토하려 해요.

06 — KPI 및 검증 계획

정말 덜 찾게 되는지, 이렇게 검증할 계획이에요

핵심 KPI

예약 정보 재탐색 소요시간

AfterBook의 핵심 목표는 예약 이후 필요한 정보를 다시 찾는 부담을 줄이는 것이에요. 그래서 특정 예약의 장소나 시간을 확인하는 데 걸리는 시간을 핵심 검증 지표로 정했어요.

기존 메시지·앱을 이용하는 방식과 AfterBook을 이용하는 방식을 비교해, 실제 탐색 시간이 줄어드는지 확인하려 해요.

보조 지표

지표측정 내용
예약 정보 탐색 성공률주어진 예약 정보를 정확하게 찾은 비율
예약 등록 완료율등록을 시작한 사용자 중 저장을 완료한 비율
예약 등록 소요시간등록 시작부터 저장 완료까지 걸린 시간
정보 추출 정확도예약 장소·날짜·시간 등 필수 항목의 정확한 추출 비율
예약 정보 수정률추출 후 하나 이상의 정보를 수정한 예약의 비율

검증 방법

  • 다양한 형식의 예약 안내문으로 등록 과정을 테스트하고, 완료 여부·소요시간·수정 항목을 확인해요.
  • 같은 예약 정보를 기존 메시지·앱에서 찾는 방식과 AfterBook에서 찾는 방식으로 비교해 탐색 소요시간과 성공률을 측정해요.

※ 아직 실제 사용자 테스트 기준값이 없어, 임의의 개선율을 성과로 제시하지 않아요. 테스트 결과를 바탕으로 구체적인 목표를 정할 계획이에요.
